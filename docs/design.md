# タスク管理アプリ 設計書

## 1. 目的

個人や小規模チームがタスクを登録し、担当・期限・優先度・進捗を管理する。初期リリースは日常的なタスク管理に必要な MVP を提供する。

## 2. MVP の機能

- タスク登録、一覧表示、詳細表示、編集、削除
- ステータス管理（未着手、進行中、保留、完了）
- タスク名、担当者、ステータス、優先度による横断検索
- 完了日時および更新日時の記録

タスクは以下の情報を持つ。

| 項目 | 備考 |
| --- | --- |
| タスク名 | 必須 |
| タスク詳細 | 任意 |
| 期限日 | 任意 |
| 優先度 | 高・中・低 |
| 担当者 | 任意 |
| ステータス | 未着手・進行中・保留・完了 |
| 作成日・更新日 | アプリが記録 |
| 完了日時 | 完了へ変更した時に記録 |

完了済みタスクを未完了のステータスへ戻した場合、完了日時を消去する。完了状態のまま編集した場合は最初の完了日時を維持する。

## 3. 対象外

検索以外のフィルタ、一覧ソート、コメント、集計ダッシュボード、ユーザー認証・権限管理は初期リリースの対象外とし、将来の拡張候補とする。

## 4. システム構成

- Web アプリケーション: Python / Flask
- 画面: Jinja2 テンプレート、HTML、CSS
- 永続化: SQLite (`instance/tasks.sqlite3`)

タスクの変更は Flask のルートで入力検証を行ったうえで SQLite に保存する。SQL はプレースホルダーを使い、タスク ID は主キーで識別する。

## 5. 主な画面・ルート

| ルート | 用途 |
| --- | --- |
| `/` | タスク一覧と検索 |
| `/tasks/new` | 新規登録 |
| `/tasks/<id>` | 詳細表示、削除 |
| `/tasks/<id>/edit` | 編集、ステータス変更 |

削除は POST リクエストのみ受け付け、画面で確認ダイアログを表示する。

## 6. 起動

```bash
pip install -r requirements.txt
python app.py
```

`TASKS_DATABASE` を設定すると SQLite ファイルの保存先を変更できる。Gemini API はタスク管理機能の実行要件ではない。
